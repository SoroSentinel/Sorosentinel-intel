# Code of conduct

SoroSentinel is a small open-source project. We want working on it to be useful and civil for everyone, whatever their experience, background or identity.

## Expected

- Be direct and kind. Critique code and ideas, not people.
- Assume good faith, and ask before concluding someone meant harm.
- Credit other people's work.
- Keep security reports private until they are fixed (see [SECURITY.md](SECURITY.md)).

## Not accepted

- Harassment, insults, or discriminatory language or imagery.
- Personal attacks, trolling, or sustained disruption of discussions.
- Publishing someone's private information without their permission.
- Sexual language or attention in project spaces.
- Introducing or suggesting deliberately harmful code, or hiding behavior in a contribution.

## Scope

This applies in every project space: issues, pull requests, reviews, commit messages and any channel run for the project. It also applies when someone represents the project elsewhere.

## Reporting and enforcement

Report a problem to the maintainers at adebisiallison2018@gmail.com. Reports are kept confidential.

Maintainers may edit or remove comments, close threads, or block anyone from the project, for as long as they judge necessary. They will tell the person why, unless that would put someone at risk.

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
